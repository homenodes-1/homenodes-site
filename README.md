# HomeNodes Site Content

A plain-text mirror of the content published at [homenodes.ca](https://homenodes.ca).

## Purpose

The live site is hosted on Squarespace, which does not keep a public revision history. This repository records each version of the site content so changes to project descriptions, scope, and claims can be traced over time.

## Contents

Each page on the site has a matching Markdown file.

| File | Page |
|---|---|
| `home.md` | Home |
| `about.md` | About |
| `research.md` | Research |
| `contact.md` | Contact |

Files are added as pages are published.

## How updates work

When site content changes, the matching file is updated here and the change is recorded in CHANGELOG.md. The live site is the published version. This repository is the record.
